# Security

ExamKlaar stores accounts, exam answers and voice recordings, so we take reports seriously.

## Reporting a vulnerability

Report it privately through [GitHub private vulnerability reporting](https://github.com/RashadAnsari/examklaar/security/advisories/new).
Do not open a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it. We reply within
5 working days and keep you updated until it is fixed.

Please test only against your own account or a local copy of the app, never against other users'
data, and give us a reasonable time to fix the problem before you disclose it.

## Supported versions

Only the latest `master`, which is what runs on [examklaar.nl](https://examklaar.nl), receives
security fixes.
